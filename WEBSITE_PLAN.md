## 1. POSICIONAMENTO & PROPOSTA DE VALOR

**Conceito Central:**
A Vibe Digital não é mais uma agência genérica. É a **única agência que entende os dois mundos**: a cultura brasileira e o mercado irlandês. Para um brasileiro empreendendo na Irlanda, trabalhar com uma agência que fala a sua língua — no sentido literal e cultural — é a diferença entre crescer ou ficar preso na mediocridade.

**Tagline Principal:**
> "Seu negócio crescendo na Irlanda. Com quem entende os dois mundos."

**Tagline Alternativa (mais agressiva):**
> "Marketing feito por brasileiros, para brasileiros que querem dominar a Irlanda."

**Diferenciais Únicos:**
1. Equipe brasileira baseada na Irlanda
2. Entende as particularidades do mercado local (behaviour do consumidor irlandês)
3. Comunicação sempre em português, sem burocracia
4. Estratégias adaptadas para negócios com dupla audiência (BR + IE)
5. Preços em euro, mentalidade brasileira

## 3. SISTEMA DE DESIGN

### Paleta de Cores
```
Primária:     #7C3AED  (Roxo vibrante — energia, criatividade, premium)
Acento:       #A3E635  (Verde-limão — crescimento, resultado, contraste)
Background:   #0D0D0D  (Preto profundo — sofisticação, dark mode)
Surface:      #1A1A1A  (Cinza escuro — cards, seções alternadas)
Text Primary: #FFFFFF  (Branco puro)
Text Muted:   #A1A1AA  (Cinza suave — subtextos)
```

**Inspiração:** Dark premium (blendd.pt) + Energia vibrante brasileira

---

### Tipografia
```
Display/H1:    Inter ou Syne — Bold, 72-96px desktop / 40-56px mobile
H2 (seções):  Inter — SemiBold, 48-56px desktop / 32-40px mobile
H3 (cards):   Inter — SemiBold, 24px
Body:          Inter — Regular, 16-18px
Caption:       Inter — Regular, 14px, cor muted
```

---

### Espaçamento
```
Section padding:   py-24 (desktop) → py-16 (mobile)
Container max:     1280px
Card padding:      p-8 (desktop) → p-6 (mobile)
Gap entre cards:   gap-6 a gap-8
```

---

### Componentes Premium
1. **Botões:** Background gradiente roxo→violeta, border-radius 8px, shine effect no hover
2. **Cards de serviço:** Borda animada gradiente no hover, fundo #1A1A1A
3. **Badge:** "Brasileiros na Irlanda" — pill com acento verde-limão
4. **Contadores:** Animação count-up ao entrar na viewport
5. **Partículas/background:** Orbs com blur gradiente no hero (inspiração blendd.pt)

---

### Animações
```
Entrada de seção:  fade-up, 300ms, delay escalonado por elemento
Hover cards:       scale(1.02), border-color transition, 200ms
CTA buttons:       Shine sweep + scale(1.03), 200ms
Contadores:        Count-up animation ao entrar na viewport
Hero background:   Orbs animados com movimento lento (keyframes)
```

## 5. TECH STACK RECOMENDADA

```
Framework:    HTML5 + CSS3 + Vanilla JS (arquivo único, sem dependências)
              OU Next.js se quiser reutilização e escalabilidade
Estilo:       Tailwind CSS (utility-first, rápido)
Animações:    CSS animations + Intersection Observer API (sem bibliotecas pesadas)
Fontes:       Google Fonts (Inter + Syne)
Deploy:       Vercel (gratuito, fácil)
Formulário:   WhatsApp link direto (wa.me/número)
```

**Recomendação:** HTML/CSS/JS puro em um único arquivo — máxima performance, zero dependências, deploy instantâneo.
